# odiogo.pt

Site pessoal de Diogo Seoane Gomes.

- `index.html` — estrutura e estilos
- `app.js` — comportamento (cartão, menu, projetos, lápis)
- `projects.js` — **lista de projetos** (é aqui que se acrescentam projetos, vídeos e fotos)
- `assets/` — imagens, texturas, vídeo e CV

Fotos novas: põe-nas em `assets/projetos/<projeto>/` e acrescenta-as ao `media` do projeto em `projects.js`, por exemplo `{ img: 'assets/projetos/china/01.jpg' }`.
